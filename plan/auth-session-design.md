# AUTH-08 / AUTH-09：数据库角色与可撤销会话

## 已确认需求

- 2026-09-22：用户选择数据库存储角色，支持刷新 token 与服务端退出。
- 前端可直接读取后端 GitHub 仓库的 `docs/` 三件套；Git 推送是该文档包的发布方式，仍需前端确认已处理 revision。
- 本文是下一阶段实施设计，不是已实现的接口契约。当前可调用接口以 `docs/frontend-api.md` 为准。

## 数据与权限边界

- 附加表脚本位于 `docs/mysql-auth-migration.sql`，已在用户授权的独立 MySQL 8 测试库完成基础验收；不由应用自动执行。连接时显式选择已确认的目标库，脚本不包含 `USE`、凭据、用户数据、授权或修改旧表的语句。
- 新库先执行现有初始化脚本，再执行附加表脚本；存量库只执行经过审核的附加表脚本。`IF NOT EXISTS` 不负责修复同名但结构不同的表，部署前必须核对实际结构。
- `user_id` 暂不建立指向存量用户表的外键，避免假设其字符集与排序规则；角色授予和会话创建必须检查用户存在。刷新凭据到新建会话表的关联由外键约束。
- 会话 ID 使用 32 字节安全随机值的小写十六进制字符串；摘要列为 32 字节二进制。时间列一律按 UTC 读写，不使用机器本地时区推断。
- 新增 `tb_user_role`，与 `tb_user` 分离，避免修改存量用户表；无角色记录的用户默认为普通用户。
- 初期只识别 `ADMIN`：仅管理员可新增、编辑、删除标签；文章、评论继续要求作者本人，不增加管理员代操作权限。
- 不开放客户端设置角色的接口，不根据手机号、登录先后或用户 ID 猜测管理员。
- 初始管理员由运维在确认目标环境、账号和备份后显式授权；应用和初始化脚本不自动授权。
- 三个服务在受保护请求中读取数据库会话状态与当前角色；撤销或降权在提交后的新鉴权请求生效，不承诺取消已通过鉴权的在途请求。
- 数据库不可用时鉴权失败关闭，返回脱敏的服务不可用错误，不回退到仅验签。

## 会话与令牌

- access token 默认 30 分钟，新增不可猜测的会话 ID claim；仅验签不足以视为已认证。
- refresh token 为密码学安全随机不透明凭据，只通过 HTTPS 请求体交换；数据库仅存 SHA-256 摘要，不存原文。
- 每次登录创建独立会话；默认绝对会话有效期 7 天，刷新不延长绝对有效期。
- 刷新使用事务和会话行锁串行处理，同一 refresh token 只能成功一次。
- 保留已消费 refresh token 摘要至会话过期，用于识别重放；旧 token 重放撤销对应整个会话，不撤销用户其他会话。
- 随机伪造 token 不触发任意用户或会话撤销；只对数据库中确实存在且已消费的摘要识别重放。
- 并发刷新中的第二个请求按重放处理，会撤销该会话；前端必须单飞刷新，跨标签页协调，网络结果不确定时要求重登，不自动重试旧 token。
- 退出只撤销当前会话及其刷新能力；其他设备会话不受影响。接口必须能够使用仍有效的 refresh token 撤销会话，避免 access token 已过期无法退出。
- 服务端持久化会话，重启后继续生效；数据库不可用时不能声称已完成退出。
- 存量无会话 ID 的 JWT 在新认证体系启用后拒绝，要求重新登录；该切换属于破坏性协议变更。

## WebSocket

- 握手复用 REST 的会话校验；撤销会话不能建立新连接。
- 已连接会话需在入站消息和出站投递前检查有效性，失效后关闭；不能只实现握手校验却宣称退出后 IM 权限立即失效。
- 定期清理过期连接，明确心跳/清理间隔。多实例下不能仅靠当前进程的退出事件广播撤销。

## 交付切片与验收

1. AUTH-08A：可重复执行的附加表迁移、数据库角色与会话设计评审；不执行远程 DDL，不改变当前接口。
2. AUTH-08B：角色读取和管理员标签保护、初始管理员运维说明、普通用户/管理员/降权/故障测试。
3. AUTH-09A：持久化登录会话、refresh token 轮换与重放撤销；覆盖成功、过期、重复、并发、事务回滚。
4. AUTH-09B：REST/IM 统一会话校验、服务端退出、重启后撤销有效性与故障关闭测试。
5. 新接口可运行并完成验证后同步 API 三件套并递增 revision，发布到后端 GitHub 仓库；设计文档不能提前替代当前契约。

## 验证要求

- 单元测试可覆盖令牌与权限规则，但不能证明 MySQL 行锁、提交、回滚及并发语义。
- 新表需在隔离 MySQL 8 测试环境验证：空库初始化、存量表兼容、重复执行、重复刷新争抢、退出/刷新竞争、角色降权。
- 不读取或输出运行配置中的连接凭据；在未确认隔离测试环境前，不执行初始化或迁移 SQL。
- 会话过期数据清理必须与重放检测保留窗口一致；先设计有界批次清理，再启用生产保留策略。
